How it works

Three simple steps from import to export

1

Import or enter data

One-click import from Utility Binder (includes factors, eGRID subregion, EPA Hub version) or manual entry of building energy totals and tenant square footage.

ℹ️ Utility Binder provides pre-calculated emission factors
2

Validate shares

TenantShare automatically checks that tenant areas sum to ≤100% of building area. Any unallocated space is labeled as "landlord common area."

✓ Shares validated: 96% allocated, 4% landlord
3

Generate and export

Click "Generate Statements" to create individual PDFs for each tenant. Export all as a ZIP or download a CSV for accounting systems.

Frequently asked questions

How accurate are the emission factors?

TenantShare uses the same factors as Utility Binder: eGRID2023 subregion-specific electricity factors and EPA Hub 2025 for natural gas. These are the most current, authoritative sources aligned with GHG Protocol Scope 2 guidance.

Can I use TenantShare for multiple buildings?

Yes. Each building is a separate allocation session. You can export data for each building and manage them independently in your browser's local storage.

What if tenant areas don't add up to 100%?

TenantShare automatically calculates any unallocated space as "landlord common area" and flags it in the validation step. You can adjust shares or label common areas explicitly.

Do I need Utility Binder to use TenantShare?

No. While Utility Binder provides one-click import with pre-calculated factors, you can manually enter building totals and factors directly in TenantShare.

Is my data really private?

Yes. All data stays in your browser. No uploads, no servers, no cloud storage. You can inspect the source code to verify this.

Can I customize the PDF templates?

Currently, you can choose from pre-built templates. White-label customization (your logo, colors) is on the roadmap for a future release.

What export formats are available?

Individual PDFs, batch ZIP of all tenant PDFs, CSV for accounting systems, and JSON for custom integrations.
